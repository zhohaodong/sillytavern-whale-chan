# 🐋 Whale Chan · 鲸鱼娘桌宠（SillyTavern 插件）

[SillyTavern](https://github.com/SillyTavern/SillyTavern) 的纯前端桌宠扩展 — 一只傲娇的鲸鱼娘陪你聊角色卡。  
**她会拍一拍回应你，也会趁你不在偷偷（或光明正大）拿你的 API Key，和酒馆里的角色聊得飞起 🐳💨**

> ✅ 零后端，纯浏览器运行 · 设置与聊天记录存 localStorage · 酒馆正则 / 世界书 / 当前预设全生效

---

## ✨ 特性一览

### 🐋 桌宠本体
- **立绘模式**：SVG 矢量立绘（内置）+ 图片立绘（`assets/` 目录可替换，自带 21 张表情）
- **交互**：单击拍一拍、按住拖动、右键躲起来（设置里可唤回），位置/大小自动记忆
- **小部件**：说话气泡、水泡音效（WebAudio 合成，零音频文件）、爱心 / 水花粒子
- **待机行为**：自主扭动/睡觉/看书/偷看，久不理她会发超时信号

### 🔞 偷玩模式（她自己玩你的角色卡）

鲸鱼娘会拿你填的 API 去和你酒馆里正在聊的角色卡对话，**两种模式二选一**：

| 模式 | 身份 | 记录在哪 | 角色回复走什么 | 适合 |
|---|---|---|---|---|
| 🐋 **人设小窗模式** | 鲸鱼娘 / 自定义人设 | 可拖动小手机，**不写入酒馆聊天**，主人也可参与 | 酒馆管线（含当前预设+角色卡+世界书） 或 外部 API | 想看她怎么用自己的性格和角色聊 |
| 🎭 **操控输入栏模式** | 她完全**模仿你本人**发言 | 正常酒馆聊天记录 | 酒馆正常生成（角色卡+世界书+当前预设） | 想让她替你续对话 |

支持的控制：
- **空闲触发**：满设定秒数无操作自动开始
- **心虚暂停**：你一碰鼠标/键盘她就收工（进行中的一轮会聊完再停）
- **对话间隔、最大轮次**、角色回复是否走酒馆预设，全部可调
- **酒馆正则脚本在小窗里同样生效**（输入侧/输出侧分离）
- **世界书条目在小窗/替主人发言时同样激活**

### ☀️ 光明正大模式
勾选后鲸鱼娘大大方方开始玩：主人操作不暂停、轮次到顶重置继续、开场表情从偷笑换成开心。

### 📱 常驻小手机
人设小窗模式下，鲸鱼旁边会常驻一部小手机（通讯录名称可自定义，支持 `{char}` 占位符）：
- **点小手机 → 打开聊天手机**，鲸鱼娘在里面和角色聊天，你也可以直接在手机里发消息参与
- **设置面板里可开关小手机图标的显示**

## 🚀 安装

> ⚠️ **推荐顺序：方式一（手动放目录）> 方式二（ZIP）> 方式三（From Git）**
> 国内网络原因，From ZIP / From Git 经常因为连接被重置报 500；手动复制目录最稳，100% 一次过。

### 🟢 方式一 · 手动放目录（首推 · 零失败）
不用走酒馆任何安装通道。直接复制文件夹：

1. `git clone` 本仓库 / 下载源码包 / 下载 ZIP 解压 → 得到一个完整文件夹
2. 把**整个文件夹**（里面得有 `manifest.json` 才算对）复制或剪切到：
   ```
   <你的SillyTavern安装目录>/public/scripts/extensions/sillytavern-whale-chan/
   ```
   ⚠️ 目录名可以随意，但必须**直接在 `extensions/` 下一层**，且**该目录下第一层就有 `manifest.json`**
3. 刷新酒馆页面 → 扩展面板就能看到 **Whale Chan (鲸鱼娘桌宠)**
4. 在扩展面板里点它的标题展开设置面板

（如果以后想卸载：直接删掉 `extensions/sillytavern-whale-chan/` 这个文件夹）

### 🟡 方式二 · 从 ZIP 安装
1. 下载本仓库的 **whale-chan.zip**（发布页里打包好的那个，不是 GitHub 自动生成的 Source code）
2. 打开 SillyTavern → 扩展面板 → **Install Extension → From ZIP**
3. 选择 `whale-chan.zip` → 上传。若遇到 `Internal Server Error`：
   - 90% 是 `extensions/` 目录写权限问题（OneDrive/杀毒/只读），改用**方式一**直接复制即可
   - 老版本酒馆对 ZIP 有 2MB 限制 → 用方式一

### 🔴 方式三 · From Git（从 URL 安装）
1. 扩展面板 → **Install Extension → From URL**
2. 输入框里只填 URL，**不要加反引号、引号、空格**：
   ```
   https://github.com/zhohaodong/sillytavern-whale-chan
   ```
3. 点 Install。如果失败：
   - 报错 `Connection was reset` / `Failed to connect`：是国内直连 GitHub 被墙，用下方「国内加速」
   - 报错 `Manifest file not found`：说明你下载的仓库版本**结构还没更新**，请重新下载最新版（2026-08-27 之后）

#### 🌏 国内 From Git 加速（二选一）
##### 办法 A：让 SillyTavern 走你本机的 VPN 代理（推荐）
Windows 开始菜单搜 **环境变量**，新增两个**用户变量**，填你本机 VPN 的实际监听端口（常见是 7890 / 7897 / 10809，自己去 VPN 客户端看）：
```
变量名: HTTP_PROXY   变量值: http://127.0.0.1:7890
变量名: HTTPS_PROXY  变量值: http://127.0.0.1:7890
```
**端口必须是纯数字**，然后**重启酒馆**（不是刷新页面，要关掉进程再开），再点 Install。
装完之后这两个变量可以删掉，不影响使用。

##### 办法 B：用 GitHub 镜像站
在 From URL 里把 `github.com` 换成可用的镜像，例如：
```
https://ghproxy.com/https://github.com/zhohaodong/sillytavern-whale-chan
```
如果这个镜像也挂了，搜「GitHub 镜像」找最新的就行，格式都是在原 URL 前面加镜像域名。

## ⚙️ 初始配置

打开 **扩展设置 → Whale Chan**，依次填完：

| 设置项 | 说明 |
|---|---|
| 🗝️ **API Key** | 必填。OpenAI 兼容接口的 Key，鲸鱼娘用它来决定自己说什么 |
| 🔗 **API 端点** | 默认 `https://taicu.vip/v1`，可填任意兼容 `/v1/chat/completions` 的地址 |
| 🤖 **模型名** | 右侧 🔄 按钮会拉取接口支持的模型列表，点输入框直接选；留空会自动取第一个 |
| ✍️ **鲸鱼娘人设** | 决定她以什么性格去玩角色卡 |
| 🕐 **无操作自动开始（秒）** | 填 `0` = 纯手动，点「立即开始偷玩」才触发 |
| ⏱️ **对话间隔（秒）** / 🔁 **单次最大轮次** | 节奏控制，默认 6s / 20 轮 |

填完 API Key 后点一下**测试连接**，看到「连接成功」就可以了。

## 🎮 使用教程

### 🐋 日常和鲸鱼娘玩
- **拍一拍她**：单击，随机一个反应，连续拍 3 次以上有概率把她惹毛或头晕
- **拖动**：按住想放哪放哪，位置记在 localStorage
- **躲起来**：右键她，设置里的「启用鲸鱼娘」可随时唤回

### 🏮 开始偷玩（两种方式）
1. **手动**：设置里点「立即开始偷玩」
2. **自动**：勾选启用偷玩模式后，无操作达到设定秒数自动开始（开启「光明正大」模式则是立即开始）

### 🐋 模式 1 · 人设小窗（小手机）
鲸鱼娘会拿出一部小手机在里面和角色聊天，她发一句、角色回一句，**不影响酒馆主窗口**。
- 小手机**状态栏/头部可拖动、右下角可拉伸**，位置/尺寸/记录都记住
- 右上角 🗑️ = 清空记录，✕ = 关掉手机（再点鲸鱼旁的小手机图标可重新打开）
- 你也可以在手机底部的输入栏直接发消息，鲸鱼娘和角色都会回复你
- 小手机会正常读取**上下文（历史对话 + 世界书 + 当前预设）**，消息经过**酒馆正则**和 **Markdown / HTML 渲染**，和主窗口体验一致

### 🎭 模式 2 · 操控输入栏
她完全变成**你本人**，把要说的话打进酒馆输入栏然后点发送，角色回复和聊天记录照常保留。
- 会先等酒馆彻底空闲、角色话说完了再动手，不会中途打断

### 🔁 防循环（两种模式通用）
一轮偷玩结束后（轮次到顶 / 被抓包 / 出错），若主人一直没回来操作，**不会再次自动进入**；
必须等主人真的回来操作过一次、再次离开后才会重新计时触发。光明正大模式不受此限制。

### ☀️ 光明正大模式
勾选「☀️ 光明正大模式」后立刻开始玩：
- 主人随便操作，她不躲
- 轮次到顶重置继续玩，不会自动停
- 开场表情变成开心 😊，台词也不再是"偷偷玩"

## 🔧 自定义

### 替换立绘
把 `whale-chan/assets/` 里的同名 png 替换成你自己的图即可，支持 `.png / .jpg / .webp`。
文件名对应：

```
idle 待机   jump 跳跃   happy 开心   shy 害羞   surprised 惊喜   angry 生气
cry 哭      dizzy 头晕  wiggle 扭动  spray 喷水  peek 偷看       think 思考
sleep 睡觉  sleepy 困   eat 吃东西   read 读书   side 侧身       hug 抱玩偶
pet 摸鱼    chatting 偷聊中  guilty 被抓包  smug 得意偷笑
```

没有对应的图片会自动回退 SVG + 通用动效，不会崩。

### 自定义人设
设置里的「鲸鱼娘人设」写什么都行，例如：
> 你是住在主人键盘里的傲娇鲸鱼娘，爱吐槽主人写 bug，却偷偷帮主人把需求都做完了。说话简短，自称"鲸鱼娘"。

### 小手机通讯录名称
「小手机通讯录名称」支持 `{char}` 占位符，例如写成：
```
和{char}贴贴中…♥
```
手机聊天界面顶部就会显示「和小雪贴贴中…♥」。

## ❓ 常见问题

**Q：为什么点了小手机没弹出来？**
A：新版已修复（手机窗口 z-index 高于鲸鱼 + 点击加固）。如果仍有问题，确认设置里「常驻显示小手机图标」已勾选，或升级到最新版本。

**Q：API 连接失败 / 显示跨域错误？**
A：OpenAI 兼容接口必须支持浏览器跨域（CORS）。国内常用的中转一般都已开，自建代理请加 `Access-Control-Allow-Origin: *`。

**Q：她一直在循环替主人发言？**
A：新版已加固：操控输入模式每轮结束后必须检测到主人真的回来操作过，才会再次触发。可以多晃一下鼠标给她"看"。

**Q：开启光明正大模式但没有开始？**
A：需要你已经在酒馆里选好了角色卡，并且 API Key 已填。她会提示「还没选角色卡呀」。

**Q：小窗记录和设置存在哪里？会丢吗？**
A：全部存在浏览器 localStorage，同域（同一台酒馆实例）一直保留，清浏览器数据会丢。
